# SCI-CALC 经典计算器

[English](README.md)

经典计算器是 SCI-CALC 的独立日常算术程序。它采用台式计算器常见的即时运算逻辑，不使用科学计算表达式编辑器，适合连续算数、价格、百分比、税额和流水合计。

当前数值会以自绘七段数码管占据 256x64 OLED 的主体。普通数值保持 35 像素高，只有长数字确实放不下时才逐级收窄；千位分隔符只影响显示，不降低内部精度。

## 基本按键

| 实际印刷按键 | 经典计算器功能 |
| --- | --- |
| `0` 至 `9` | 输入数字 |
| `.` | 输入小数点 |
| `EXP` | 输入 `00` |
| `+`、`-`、`*`、`/` | 选择四则运算 |
| `Enter` | 等号 |
| `^` | 百分比 |
| `ANG` | 切换当前数值正负号 |
| `Backspace` | 删除最后一位输入 |
| `COT` | CE，只清除当前输入 |
| `ESC` | AC，清除当前整项计算 |
| `EXTRA` | 撤销最近一次已经完成的算术步骤 |
| `TAB` | 打开或关闭纸带记录 |
| 长按 `ESC` 一秒 | 从 SD 卡恢复 `/main.bin` 并返回主固件 |

运算符采用经典即时运算。例如，`2 + 3 * 4 Enter` 的结果是 `20`：按下 `*` 时先完成 `2 + 3`，再开始乘法。还没有输入下一个数时再次按运算符，会替换刚才的运算符。

`Enter` 会记住上一次运算及其右操作数，因此 `10 + 5 Enter Enter` 依次得到 `15` 和 `20`。输入 `5 + Enter` 时，缺少的第二个数自动使用 `5`，结果为 `10`。

输入最多保留 15 位有效数字，与 ESP32 双精度浮点数的实际有效精度相符。极大或极小结果会自动使用七段式 `E` 记数法。除数为零或结果溢出时会明确报错，输入新数字或按 `ESC` 即可重新开始。

## 百分比与税率

百分比使用商业计算器习惯，并会立即完成当前待执行的运算：

| 按键顺序 | 结果 |
| --- | --- |
| `200 + 10 ^` | `220` |
| `200 - 10 ^` | `180` |
| `200 * 10 ^` | `20` |
| `200 / 10 ^` | `2000` |
| `10 ^` | `0.1` |

税率快捷键使用已经保存的税率：

| 按键 | 功能 |
| --- | --- |
| `Shift` + `+` | 给当前数值加税 |
| `Shift` + `-` | 从含税金额反算税前金额 |
| `Shift` + `^` | 将当前数值保存为税率，可设范围为 0 至 99.99% |

税率为 13% 时，输入 `100` 后按住 `Shift` 再按 `+` 得到 `113`；输入 `113` 后按住 `Shift` 再按 `-` 则反算得到 `100`。存在待执行运算时，也可以先给第二个操作数进行含税或去税换算。

## 存储器与总计

本程序将六个印有三角函数名称的按键改作常见存储器操作：

| 实际印刷按键 | 功能 |
| --- | --- |
| `SIN` | M+，把屏幕数值加到存储器 |
| `COS` | M-，从存储器减去屏幕数值 |
| `TAN` | MR，把存储器数值调入当前输入 |
| `SEC` | MC，清空存储器 |
| `CSC` | 调出总计 GT |
| `Shift` + `CSC` | 清空总计 GT |

存储器数值及其启用状态会跨重启和程序切换保留。每次用 `Enter` 完成运算，或用百分比键完成待执行运算时，其结果都会加入 GT；GT 会保留到手动清空或设备重启。顶部的 `M`、`GT`、`U` 分别表示存储器、总计和单步撤销当前可用。

## 纸带记录

内存纸带保存最近 24 条已完成运算，不写入 SD 卡，也不会因为频繁算账而反复写 Flash。

| 按键 | 纸带功能 |
| --- | --- |
| `TAB` | 打开或关闭纸带 |
| `8` / `2` | 移到更早或更新的记录 |
| `Enter` | 将选中记录的结果调回计算器 |
| `Backspace` 或 `ESC` | 返回计算器 |
| `Shift` + `Backspace` | 清空全部纸带 |

## 账务设置

按 `Shift` + `TAB` 进入设置。用 `8`、`2` 选择项目，用 `4`、`6` 修改；按 `TAB`、`Backspace` 或 `ESC` 返回。

- 小数位：`AUTO`、`0`、`2` 或 `4` 位。
- 舍入：四舍五入、向零截断或远离零向上舍入。
- 千位分隔：显示或隐藏逗号。
- 税率：在 0 至 99.99% 之间以 0.25 个百分点调整。

固定小数模式会对每一步已经完成的算术结果进行舍入，适用于中间步骤也必须保持分币精度的账务。设置和存储器保存在 NVS 中；纸带与 GT 只保留在 RAM 中，避免不必要的 Flash 写入。

## 安装

1. 将 [`classiccalc.bin`](../../sci_calc_code/bin/classiccalc.bin) 复制到 SD 卡根目录，保存为 `/classiccalc.bin`。
2. 将当前 [`main.bin`](../../sci_calc_code/bin/main.bin) 复制到 SD 卡根目录，保存为 `/main.bin`。
3. 进入 `Programs > Calculation > Classic Calc`。

如需通过 USB 完整安装，请将 [`sci-calc-full-1x.xx-min-spiffs.bin`](../../sci_calc_code/bin/sci-calc-full-1x.xx-min-spiffs.bin) 刷写到地址 `0x0`。

## 编译与测试

```powershell
cd games\ClassicCalculator
& "$env:USERPROFILE\.platformio\penv\Scripts\platformio.exe" run
python -m unittest discover -s tests -v
Copy-Item .pio\build\classic_calculator\firmware.bin ..\..\sci_calc_code\bin\classiccalc.bin -Force
```

生成的 `classiccalc.bin` 是应用分区镜像。只有在地址 `0x0` 完整安装时才使用合并镜像。
