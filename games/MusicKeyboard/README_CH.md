# 高级音乐键盘

[English](README.md)

高级音乐键盘把计算器变成一台紧凑的 16 复音乐器。程序通过有线 PCM5102A 输出声音，可显示实时琴键或示波器，提供六种音色，并能把演奏录制为 SD 卡上的标准 MIDI 文件。

本应用使用独立固件镜像。运行普通计算器主固件时，它不会占用主应用分区的程序空间。

## 硬件接线

| 设备 | 接线 |
| --- | --- |
| PCM5102A BCK | GPIO21 |
| PCM5102A LCK/LRCK/WS | GPIO22 |
| PCM5102A DIN | GPIO15 |
| PCM5102A SCK | GND |
| PCM5102A 供电 | VCC 与共地 GND |
| OLED | CS GPIO5、DC GPIO16、RST GPIO17、MOSI GPIO23、SCK GPIO18 |
| SD 卡 | CS GPIO4、MOSI GPIO23、MISO GPIO19、SCK GPIO18 |

键盘继续使用计算器原有的 GPIO 矩阵，不需要增加输入接线。

## 安装与启动

把 `musickeyboard.bin` 复制到 SD 卡根目录并命名为 `/musickeyboard.bin`，同时保留当前主固件 `/main.bin`。进入 `Programs > Music > Music Keyboard` 启动。

长按 `ESC` 一秒会恢复 `/main.bin` 并返回计算器。短按 `ESC` 会立即停止全部声音。

## 页面

按 `TAB` 在四个页面之间循环：

- `KEYS`：显示当前音符和两组八度的琴键动画
- `SCOPE`：显示实时波形、输出峰值、活动复音数和合成器 CPU 占用
- `REC`：显示录制或回放时间、事件容量和保存后的文件名
- `SET`：显示音色、音区、移调、布局、力度、音量、速度、延音和节拍器状态

切换页面不会打断正在保持的音符。

## 演奏

默认 `CALC` 布局沿用经典音乐计算器熟悉的音符顺序。程序会先应用根音、八度和移调，再把最终音符送往合成器与录音器，因此换调后仍可沿用相同指法。

| 按键 | 计算器布局中的音符 |
| --- | --- |
| `.` | 根音下方的低音 La |
| `0` | 根音下方的低音 Si |
| `1` 至 `7` | 根音、二度、三度、四度、五度、六度、七度 |
| `8` | 高一个八度的根音 |
| `9` | 高一个八度的二度 |
| `/`、`*`、`-`、`+`、`^` | 高一个八度的三度至七度 |
| 按住 `ENTER` 再按任意音符键 | 临时升高该音符一个八度，例如 `ENTER+3` 就是高音 3 |

科学功能键用于补齐升音与更高的升音：

| 实体键 | 入门记法 | 相对根音 |
| --- | --- | --- |
| `SIN` | 升 1 | +1 半音 |
| `SEC` | 升 2 | +3 半音 |
| `COS` | 升 4 | +6 半音 |
| `CSC` | 升 5 | +8 半音 |
| `TAN` | 升 6 | +10 半音 |
| `COT` | 高音升 1 | +13 半音 |
| `EXP` | 高音升 2 | +15 半音 |
| `RPN/NORM` | 高音升 4 | +18 半音 |

`RPN/NORM` 就是 `EXP` 右侧的实体键。转换谱中简写为 `RPN`；面板上没有名为 `Extra` 的按键。

运算键扩展按照印刷键顺序排列：`/`、`*`、`-`、`+`、`^` 依次是高音 `3`、`4`、`5`、`6`、`7`。在计算器布局中，`ENTER` 是按住即用的临时高八度键，不会改变全局音区；松开后原来的数字指法立即恢复。在和弦与半音布局中，运算键仍保留原来的和弦垫功能。

按 `Shift+TAB` 会切换到 `CHORD` 和弦布局。它保留计算器音符顺序，并把运算键变成和弦垫，每个三和弦只需一个物理按键：

| 按键 | 和弦 |
| --- | --- |
| `*` | I 级大三和弦 |
| `/` | ii 级小三和弦 |
| `-` | IV 级大三和弦 |
| `+` | V 级大三和弦 |
| `^` | vi 级小三和弦 |

第三种 `CHROMATIC` 半音布局把 `1 2 3 4 5 6 7 8 9 0 . ENTER` 映射为连续十二个半音。运算键仍是和弦垫，科学功能键从下一个八度继续向上排列。

## 演奏设置

| 快捷键 | 功能 |
| --- | --- |
| `Shift+1` / `Shift+3` | 上一种或下一种音色 |
| `Shift+4` / `Shift+6` | 降低或提高一个八度 |
| `Shift+2` / `Shift+8` | 降低或提高一个半音的移调 |
| `Shift+/` / `Shift+*` | 上一个或下一个根音 |
| `Shift+TAB` | 循环切换计算器、和弦和半音布局 |
| `Shift+-` / `Shift++` | 降低或提高音量 |
| `Shift+7` / `Shift+9` | 每次降低或提高 5 BPM |
| `Shift+^` / `Shift+EXP` | 降低或提高固定力度 |
| `ANGLE` 或 `Shift+5` | 开关延音 |
| `Shift+.` | 开关节拍器 |
| `BACKSPACE` | 停止全部声音 |
| `Shift+ANGLE` | 直接打开设置页 |

可选音色包括钢琴、电钢琴、风琴、温暖铺底、主奏合成器和钟声。录音期间的音色切换会保存为 MIDI Program Change 事件。

## 录制

| 快捷键 | 功能 |
| --- | --- |
| `Shift+0` | 开始或停止录制 |
| `Shift+ENTER` | 播放或停止内存中的录音 |
| `Shift+BACKSPACE` | 清除内存中的录音 |

停止录制后，程序会依次寻找可用文件名并保存到独立的 `/recordings/KEYS000.MID` 至 `/recordings/KEYS999.MID`，不会混入普通音乐曲库。文件采用 MIDI Format 0，包含音符力度、延音、音色变化和速度变化；只有希望音乐播放器收录时，才需要把成品移动到 `/music`。

固定录音缓冲区可保存 2048 个事件，占用约 16 KB 内部 RAM。缓冲区写满时会自动停止并保存。若没有 SD 卡或写入失败，录音仍会留在 RAM 中供立即回放，直到退出应用或开始下一次录音。

## MIDI 转按键谱

项目内的 `tools/midi_to_calc.py` 可以在电脑上把标准 MIDI 转成音乐键盘的 CALC 按键谱。它会优先选择命名为旋律、主奏或人声的轨道，并排除鼓点、音效及音高几乎不变的触发轨。

先进入本目录并安装一次依赖：

```powershell
python -m pip install -r tools/requirements.txt
```

直接转换并在终端显示完整谱面：

```powershell
python tools/midi_to_calc.py "C:\Music\song.mid"
```

长曲建议保存为文本并关闭终端长输出：

```powershell
python tools/midi_to_calc.py "C:\Music\song.mid" --out "song_calc.txt" --quiet
```

| 参数 | 用途 |
| --- | --- |
| `--track N` | 手动选择概览表中的 MIDI 轨道编号 |
| `--grid 16` | 使用十六分音符网格；默认是八分音符 |
| `--chords` | 额外生成完整和弦建议；长曲输出会明显增加 |
| `--full-track` | 不自动分离同一轨道内明显分开的低音伴奏 |

谱面中的 `RPN` 是实体 `RPN/NORM` 键的缩写；`↑x` 表示按住 `ENTER` 再按 `x`。默认转换不会输出和弦段，以免长曲被数百个和弦时间片淹没。

## 硬件限制

- 机械按键不能感知压力或敲击速度，因此使用 `Shift+^` 与 `Shift+EXP` 调整统一的 MIDI 力度。
- 合成器最多支持 16 个同时发声的音符。这足以覆盖普通按键演奏和多个重叠三和弦，同时给无 PSRAM 的 ESP32-WROOM-32E 留出可靠余量。
- 录制保存的是音符事件而不是 PCM 音频。这样可以用很少的 RAM 保存较长演奏并获得可编辑 MIDI，但在其他合成器上播放时，音色可能不同。
- 音频以 44.1 kHz 和固定大小缓冲区生成。示波器中的 CPU 百分比只统计合成计算，不包含等待 I2S 输出的时间。
