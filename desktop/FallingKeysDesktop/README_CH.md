# Falling Keys Desktop

Falling Keys Desktop 是面向 SCI-CALC 计算器的现代桌面下落音游。电脑负责绘制轨道、生成击键音效和判定时机，计算器通过 USB 串口作为控制器使用。

## 环境要求

- Windows 10 或更新版本
- Node.js 和 Electron 37 或兼容的 Electron 运行环境
- Python 3.10 或更新版本
- 安装 `SerialKeyboard` 客户端所需的 `pyserial`
- 已提供 SerialKeyboard 程序的 SCI-CALC 固件

在项目根目录安装 Python 依赖：

```powershell
python -m pip install -r games\SerialKeyboard\pc\requirements.txt
```

## 启动

在当前目录执行：

```powershell
npm start
```

程序默认将 COM7 作为建议端口。端口不确定时点击 Scan，再连接计算器，然后开始游戏。程序不会把计算器按键注入到 Windows 的其他应用中。

点击“观看演示”可以在没有计算器和串口的情况下自动完成一局 Perfect 演奏，适合检查 MIDI 编曲、展示画面或测试音频输出。

如果尚未安装本地 Electron，可以先使用全局 `electron` 命令；也可以在当前目录执行一次 `npm install` 完成本地安装。

## 谱面

桌面播放器可以直接加载标准 `.mid` 和 `.midi` 文件。程序会在每个起音时刻自动选择一个主旋律音符供玩家操作，其余音符作为较轻的电脑伴奏自动播放，不要求理解轨道名、通道名或音高对应关系。程序也兼容旧版 PTC1 谱面格式：

```text
PTC1
title=Example
artist=SCI-CALC
lanes=4
bpm=120
offset=0
N,time_ms,lane,note,duration_ms
N,1000,0,60,0
N,1500,1,62,0
N,2200,2,64,500
```

`lane` 从 0 开始，范围必须为 0 到 5。时间和时长的单位是毫秒，均以谱面开始为基准。时长大于 0 会生成长按音符。导入谱面使用谱面声明的轨道数；内置演示谱面可以选择 4、5 或 6 轨。

设置页提供四种模式：流畅模式判定宽松、预览距离较长；街机模式是标准体验；疾速模式会压缩判定窗口并缩短预览距离；镜像模式会按乐句翻转可见轨道。所有模式仍然只要求操作自动选出的主旋律，伴奏不会变成第二套按键。

界面默认使用英文。通过右上角语言选择器可以切换为中文，选择会保存在本机。

## 计算器按键

程序保留固件游戏使用的物理矩阵列映射：第 1 到第 6 列分别对应第 1 到第 6 轨。同一列中的任意按键都可以击打对应轨道，玩家可以选择顺手的行。ESC 用于暂停，SHIFT 保留给计算器自身功能，游戏会忽略它；重复串口事件不会重复判定。

## 输入时序校准

开始游戏前先连接计算器，在准备区的“时序校准”面板中选择速度和测量拍数。四拍预备拍之后，每个节拍按一次任意轨道按键，并在下一拍前松开。程序使用有效样本的中位数，并在样本较多时去掉极端值；结果会保存在本机，并应用到所有游戏模式的实体按键判定。

正数表示串口事件到达较晚，因此游戏会将这次输入的判定时间提前相应毫秒。校准不会改变谱面、伴奏或观看演示的时序，也无法让实时声音在实体按键事件到达之前播放。点击“清零”可以删除保存的校准值。

## 时序和音效

程序使用 Web Audio 时钟驱动画面，并将串口事件映射到同一局游戏时钟。声音时间轴与按键判定相互独立：主旋律和伴奏都会按照谱面时间自动播放，计算器按键只影响画面反馈、连击、准确率和得分。提前按、漏按或长按失败都不会中断音乐，也不会重复触发音符。声音在本机合成，最高分保存在 Electron 用户目录中。

## 故障排查

- 如果端口一直离线，请关闭占用该 COM 口的其他程序，并确认计算器正在运行 SerialKeyboard 固件。
- 如果 Python 桥接程序无法启动，可以将 `SCI_CALC_PYTHON` 设置为 Python 可执行文件的完整路径。
- 如果谱面加载失败，请检查 `PTC1` 签名、`N,` 音符行、轨道范围，并确认至少存在一个音符。
