# SCI-CALC 高级音乐键盘桌面版

[English](README.md)

这是计算器 `MusicKeyboard` 的 Electron 桌面复刻版。计算器仍然作为实体控制器，桌面端接收 `SKB1` 串口按键事件并使用 Web Audio 发声，不会把按键注入 Windows。

## 已包含功能

- 与固件一致的 5x6 计算器按键布局和音符映射。
- Keys 页面提供钢琴视角和计算器视角；计算器视角按实体 5x6 键位排列，并实时显示按下和发声状态。
- 计算器、和弦、半音三种布局。
- Piano、E.Piano、Organ、Warm Pad、Lead、Bell 六种音色。
- 独立的桌面“模拟合成器”页面，提供双振荡器、微调、噪声、低通滤波器、ADSR、音高 LFO 和可保存预设。
- 独立的 Groove 页面，提供 16/32 步鼓机和由计算器控制的琶音器。
- 和弦伴奏助手，支持大三、小三、七和弦、挂四和弦，可选自动低音和按 BPM 重触发的低音脉冲。
- 固定长度的分层循环叠录，支持基础层、按循环边界叠录、单层静音和删除。
- MIDI 跟弹挑战，支持片段预览、限时计算器按键、连击计分和递增难度。
- 只在本次会话内保存的采样键盘，支持导入音频、切片、起止范围和速度控制。
- 声音实验台，提供实时波形、平滑轨迹和频谱视图。
- 所有音色在松键时都会从当前起音或衰减音量平滑释放，不再先突然加重。
- 16 复音、延音、节拍器、八度、根音、移调、音量、力度和 BPM 控制。
- Keys、Learn、Scope、Recorder、Convert、Settings、Synth 和 Groove 八个页面。
- MIDI 引导教学，提供仅旋律、简单和弦、完整和弦三档复杂度；下一步需要弹奏的计算器键和钢琴键会持续高亮。
- 输入时序校准，支持节拍采样、稳健中位数计算、全局偏移保存和每次 5 ms 的手动微调。
- 内置 MIDI 转计算器谱页面，支持自动选旋律、八分或十六分网格、可选和弦建议，以及完整轨道/手动轨道选项。
- Scope 可选 15、30、60、120 FPS，在流畅度和 CPU 占用之间选择。
- 最多 2048 个事件的内存录音、回放和标准 Format 0 MIDI 导出。
- 默认英文界面，可切换中文。

## 使用条件

- Windows 和 Electron 37 或其他较新的 Electron 运行环境。
- 已启用 SerialKeyboard 接口的 SCI-CALC 固件。
- 通过 USB 连接计算器。串口桥使用 115200 波特率和现有 Python `pyserial` 依赖。
- 连接到电脑的扬声器或耳机。

## 启动

```powershell
cd desktop\MusicKeyboardDesktop
npm install
npm start
```

点击 **Refresh** 枚举串口，选择计算器端口（例如 `COM7`），点击 **Enable audio**，再点击 **Connect**。桌面端收到计算器的设备信息包后，才会显示为已连接。

Python 桥接程序是只读的。它解析计算器协议并向 Electron 发送结构化事件，不会生成 Windows 键盘输入，也不会向计算器串口写数据。

## 演奏

普通计算器按键直接演奏音符。在 Calculator 布局中，先按住 `ENTER` 再按音符键，可以演奏高一个八度。Chords 布局中，`*`、`/`、`-`、`+`、`^` 是和弦键。桌面端可以用 `TAB` 切换八个页面，计算器实体按键的页面操作仍以固件文档为准。关于通用简谱读法和计算器按键对应关系，请看[《通用简谱读法》](../../docs/numbered_notation_CH.md)。

## 模拟合成器

打开 **Synth** 页面，可以在“内置音色”和“自定义音色”之间切换。自定义引擎使用两个 Web Audio 振荡器、第二振荡器微调、滤波噪声、带共振的低通滤波器、振幅 ADSR 包络和音高 LFO。预设包括 Init Poly、Warm Pad、Bright Lead、Mono Bass 和 Digital Bell。参数修改会作用于之后开始的音符，并保存在本机；原有 16 复音上限和计算器按键映射保持不变。

## Groove

打开 **Groove** 页面可以制作桌面端本地节奏循环。鼓机包含底鼓、军鼓、踩镲和拍手四条轨道，支持 16 或 32 步、1/8 或 1/16 网格、清空、随机生成、共享 BPM 和播放指示器。节奏型会保存在桌面端，并可与计算器实时演奏同时运行。

开启 **琶音器** 后，按住一个或多个计算器音符，可以选择上行、下行、上行/下行或随机模式。还可以调整速率、跨越八度数和占空时间。关闭琶音器后，按键恢复直接演奏。琶音器沿用当前桌面音色、移调、力度和 16 复音限制，不会改变计算器固件。

### 和弦伴奏

在 **和弦伴奏** 面板开启助手并按住一个计算器音符。根音默认生成大三和弦，也可以选择小三、七和弦或挂四和弦。开启**自动低音**会在根音下方加入一个低音；同时开启**低音脉冲**时，低音会按共享 BPM 反复触发，而不是持续按住。和弦助手与琶音器互斥，因此一个按住的按键始终只有一种明确的解释。

### 分层循环叠录

在 **分层循环** 面板选择 1、2、4 或 8 小节，然后点击 **录制基础层** 并演奏第一层。录制开始时会根据当前 BPM 固定循环长度，循环结束后自动进入播放。

循环播放期间点击 **录制新层** 会准备叠录；真正录制会在下一次循环边界开始，因此每一层都会保持对齐。在边界到来前再次点击可以取消待录制层。每一层都可以单独静音或删除。**停止循环** 会停止播放但保留各层，**清空各层** 会全部删除。循环引擎不会把自己的播放内容再次录入，停止时也只释放循环产生的声音。

## MIDI 引导教学

打开 **Learn**，选择 MIDI 文件和和弦复杂度。**仅旋律**每一步要求一个主旋律音；**简单和弦**加入一个能同时弹奏的和声音；**完整和弦**最多保留四个能够在计算器上同时按下的音。开始教学后，程序会自动应用推荐的根音和音区、切换到 Calculator 布局并打开 Keys 页面。金色表示下一步目标键，按对后变为绿色；完成整组按键后自动进入下一步。出现 `ENTER` 高亮时，需要先按住 `ENTER`，再按其他高亮键。

教学不限制速度，会一直等待用户弹奏。钢琴或计算器视图上方提供**上一步**、**跳过**和**停止教学**。切换和弦复杂度后，会使用当前 MIDI 重新生成教学步骤。

## 跟弹挑战

**跟弹挑战**使用当前已经生成的教学 MIDI。选择简单、普通或困难后开始一轮，桌面端会先预览一小段，随后进入**轮到你**，并在计算器视图中高亮下一步需要按的键。和弦以及 `ENTER` 会作为一个整体检查，必须完成整组按键才算通过。

挑战会在当前会话中记录分数、连击、错误和命中率。三种难度有不同的初始片段长度和输入时间窗；每完成两轮，片段会逐渐变长，直到该难度的上限。错过步骤会中断连击，并在时间窗结束后进入下一步。启用桌面音频时才会播放预览；串口仍只作为输入设备，不会向 Windows 发送键盘事件。

Shift 层与固件保持一致：

| 计算器组合键 | 功能 |
| --- | --- |
| `SHIFT+1` / `SHIFT+3` | 上一个 / 下一个音色 |
| `SHIFT+4` / `SHIFT+6` | 八度降低 / 升高 |
| `SHIFT+2` / `SHIFT+8` | 移调降低 / 升高 |
| `SHIFT+/` / `SHIFT+*` | 根音降低 / 升高 |
| `SHIFT+-` / `SHIFT++` | 音量降低 / 升高 |
| `SHIFT+7` / `SHIFT+9` | BPM 降低 / 升高 |
| `SHIFT+^` / `SHIFT+EXP` | 力度降低 / 升高 |
| `SHIFT+5` | 延音开关 |
| `SHIFT+.` | 节拍器开关 |
| `SHIFT+0` | 开始或停止录音 |
| `SHIFT+ENTER` | 播放或停止当前录音 |
| `SHIFT+BACKSPACE` | 清除当前录音 |
| `SHIFT+TAB` | Calculator / Chords / Chromatic |
| `SHIFT+ANGLE` | 打开 Settings |
| `SHIFT+EXTRA` | 紧急静音 / 关闭所有音符 |

## MIDI 转计算器谱

打开 **Convert** 页面，选择 `.mid` 或 `.midi` 文件后点击 **Convert MIDI**。桌面端会调用项目内持续维护的转谱工具：自动选择可靠的旋律轨、修复缺少 Note Off 的结尾音符、把密集片段整理成可演奏旋律，并输出与命令行工具一致的 `CALC` 谱格式。自动选轨不合适时，可以填写 **Melody track**；轨道编号沿用转换器的从 0 开始编号。只有需要时再勾选 **Include chord suggestions**，因为长曲报告会明显变长。

转换器需要 `games\MusicKeyboard\tools\requirements.txt` 中列出的 Python 依赖。报告只显示在桌面端，不会改写 MIDI 文件。

## 输入时序校准

打开 **Settings**，先启用音频，再使用 **输入时序校准**。程序会先播放 4 个预备拍，然后播放 8、12 或 16 个测量拍。每个节拍按一次音符键，并在下一个节拍前松开。结果使用有效样本的中位数，较长测量还会剔除极端样本。正数表示串口按键事件晚于参考节拍到达，全局校正会让录音事件时间戳提前相应毫秒。校准值会保存在本地，也可以用 5 ms 步进手动微调。

这个校准会修正录音和将来的有时间基准功能，不能让实时声音在实体按键事件到达之前播放，因此不会宣称消除物理输入到声音的因果延迟。

## Scope 刷新率

Scope 页面提供 15、30、60、120 FPS。音频引擎仍按正常 Web Audio 速率运行，这个选项只改变诊断波形和声音实验台的绘制频率。

### 采样键盘

打开 **Synth**，点击**选择音频**，选择 WAV、MP3、OGG 或浏览器能够解码的其他音频文件。解码后的音频只保存在本次桌面会话的内存中。可以把片段数设为 2 到 12，调整起止范围，并把速度设为 0.50x 到 2.00x。开启**采样模式**后，计算器会触发采样片段而不是合成器音符。可用按键顺序为 `1 / 2 / 3 / 4 / 5 / 6 / 7 / 8 / 9 / 0 / . / SIN`；采样模式下其他音符键会被忽略，但切页和紧急静音等全局控制仍可使用。采样模式、琶音器和和弦伴奏不会同时运行。

### 声音实验台

**声音实验台**位于 Scope 波形下方。**实时波形**是当前分析器数据，**滤波轨迹**是仅用于显示的移动平均，**频谱**显示分析器频段。平滑和显示增益只影响绘图，不会改变合成器、采样播放、复音上限或录音数据。

## 录音和 MIDI

停止非空录音时会自动打开保存对话框，与计算器工作流一致。也可以在 Recorder 页面点击 **Save MIDI**。默认目录为 `Documents\recordings`，文件名类似 `KEYS000.MID`；取消对话框后录音仍保留在内存中。

## 故障排查

- 如果没有串口，请根据 `games\SerialKeyboard\pc\requirements.txt` 安装现有 PC 依赖，重新插拔 USB，再点击 **Refresh**。
- 如果一直显示 Connecting，请确认计算器运行的是支持 SerialKeyboard 的主固件，并确认没有其他程序占用同一个 COM 口。
- 如果示波器和计数器有变化但没有声音，请点击 **Enable audio** 并检查 Windows 音频输出设备。
- USB 断开或按键释放异常后，可以点击 **Panic / silence**。
